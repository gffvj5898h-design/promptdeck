# PromptDeck

Мобильная PWA-библиотека самодостаточных промтов для изображений.

Сайт: https://gffvj5898h-design.github.io/promptdeck/

## Версия 0.3

- Светлый адаптивный интерфейс: навигация на компьютере и нижняя панель на телефоне.
- 123 промта, поиск по названиям, текстам и псевдонимам; избранное и история.
- Подборка из восьми приёмов по предоставленному пользователем видео от 18.10.2026.
- Фото остаётся в памяти вкладки; системное меню отправки вызывается только пользователем.
- Старые ключи избранного и настроек сохранены. `/explodedview` — псевдоним `/exploded`.

Ярлыки вида `/blueprint` обозначают шаблоны PromptDeck, а не встроенные команды сторонних ИИ-сервисов. Полный текст составляется при открытии карточки.

В ролике показаны названия приёмов и результаты. Развёрнутые инструкции написаны для приложения по этим приёмам, они не являются дословной расшифровкой автора видео. Для скрытой геометрии, внутреннего устройства, разрезов, рентгена и микровида в шаблонах обозначены ограничения достоверности.

## Публикация

GitHub Pages развёртывается из `main` через `.github/workflows/deploy-pages.yml`.

## Проверка

`node --check app.js` и синтаксическая проверка всех файлов `data/*.js` и `service-worker.js`.
